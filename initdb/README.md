# initdb — создание баз под задачу

Скрипты `*.sql`, `*.sql.gz` и `*.sh` из этой папки выполняются автоматически при
первом старте **пустой** PGDATA (т.е. при развёртывании нового инстанса).

- Выполняются в порядке имён (00-, 01-, ...).
- На уже инициализированной базе не запускаются.
- Кладите сюда только общие имена БД/схем под конкретную задачу — без значений и секретов.

Пример:

```sql
-- 01-create-dbs.sql
CREATE DATABASE first_db;
CREATE DATABASE second_db;
```
