# initdb — создание баз под задачу

Образ PostgreSQL выполняет скрипты из `/docker-entrypoint-initdb.d` при
инициализации нового кластера. Локально Compose подключает `./initdb`. Для
Portainer Agent скопируйте скрипты в серверный каталог `POSTGRES_INITDB_DIR`
до деплоя. Сохраните право исполнения у `10-create-databases.sh`.

- Выполняются в порядке имён (00-, 01-, ...).
- На уже инициализированной базе не запускаются.
- Кладите сюда только общие имена БД/схем под конкретную задачу — без значений и секретов.

Если скрипт завершился ошибкой после создания кластера, перезапуск может
поднять PostgreSQL с частично применённой инициализацией. Проверьте логи и
наличие ожидаемых баз. Выполните пропущенные шаги вручную после исправления ошибки.

Пример (статичный SQL):

```sql
-- 01-create-dbs.sql
CREATE DATABASE first_db;
CREATE DATABASE second_db;
```

Для создания БД по списку из переменной окружения используйте
`initdb/10-create-databases.sh` — он прочитает `INITDB_DATABASES`
(имена через пробел) и создаст отсутствующие базы. Имена задаются в env,
а не в этом репозитории.
